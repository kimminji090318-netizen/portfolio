## 🚀 주요 프로젝트

### 1. 💄 딱맞뷰티 - 퍼스널 컬러 진단 웹앱

**설명**: AI 기반 피부톤 분석 및 개인 맞춤형 뷰티/패션 추천 서비스

**기술 스택**: Google Apps Script, HTML5, JavaScript, CSS3

**핵심 기능**:
- ✅ 개인 정보 입력 화면 (이름, 나이, 성별, 조명 환경 선택)
- ✅ 카메라/사진 업로드를 통한 피부톤 측정 및 Lab 색상 공간 분석
- ✅ 독자적으로 지정한 퍼스널 컬러 색상 기준 (봄/여름/가을/겨울 웜/쿨)
- ✅ 진단 결과: 추천 색상 팔레트, 패션 코디, 화장품 추천, 단계별 메이크업 가이드
- ✅ Google Sheets 자동 연동으로 진단 결과 기록

**주요 기술 구현**:
- 색상 이론 및 Lab 색상 공간 이해
- Google Apps Script의 HtmlService를 활용한 웹앱 개발
- 클라이언트-서버 통신 (google.script.run)
- Google Sheets API 연동
- 반응형 웹 디자인 구현

**폴더 구조**:
```
딱맞뷰티/
├── index.html      # 메인 UI 및 클라이언트 사이드 로직
└── code.gs         # Google Apps Script 백엔드
```
