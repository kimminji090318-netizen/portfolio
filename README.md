## 🔑 API 키 안전하게 다루는 방법

이 포트폴리오의 프로젝트들은 **Google Gemini API** 같은 외부 AI API를 사용합니다.  
API 키는 **절대 공개하면 안 되는 중요한 정보**예요.

### ⚠️ 하면 안 되는 것
```javascript
// ❌ 절대 이렇게 하지 말 것!
const API_KEY = "AIza1234567890abcdef...";
```

### ✅ 올바른 방법
```bash
# 1. .env 파일 만들기 (로컬에서만)
cp .env.example .env

# 2. 본인 API 키만 입력 (이 파일은 GitHub에 올리지 않음)
# GEMINI_API_KEY=your_actual_key_here
```

### 📋 파일 구조
```
portfolio/
├── .env (로컬에만 있음 - GitHub 제외)
├── .env.example (공개 - 양식만 보여줌)
├── .gitignore (.env 제외 설정)
└── projects/
```
