## 🔐 API 키 보안 안내

이 저장소는 공개 포트폴리오이므로 **실제 API 키를 코드, README, 이미지, 커밋에 넣지 않습니다.**

- 소스 코드의 키 입력 자리는 `"[please use your ai api key]"`라는 자리표시자로 둡니다. 이 문구는 실제 API 키가 아니므로 AI API 호출에 사용할 수 없습니다.
- `.env.example`은 설정 항목을 보여주는 예시 파일입니다. 실제 비밀 값은 로컬의 `.env` 또는 서버 환경변수에 보관하고, `.env`는 GitHub에 올리지 않습니다. 현재 `.gitignore`는 `.env`와 `.env.*`를 제외하면서 `.env.example`은 유지하도록 설정되어 있습니다.
- **일반 HTML/JavaScript는 브라우저에서 실행될 때 `.env`를 자동으로 읽지 않습니다.** 프런트엔드 코드에 실제 키를 넣으면 사이트 방문자가 확인할 수 있으므로 공개 웹앱에서는 사용하지 않습니다.
- 실제 Gemini API를 연결하려면 백엔드나 서버리스 함수에서 서버 환경변수로 키를 읽고, 브라우저는 해당 서버를 호출하도록 구성합니다. API 키의 사용량 및 권한 제한도 설정하세요.
- 실제 키를 공개 저장소나 커밋 이력에 올린 적이 있다면 현재 코드에서 지우는 것만으로는 충분하지 않습니다. 제공사 콘솔에서 해당 키를 폐기하고 새 키를 발급하세요.
