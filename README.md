## 보안 안내

프로젝트에 Google Gemini API, OpenAI API, 또는 다른 외부 AI API를 연동하는 경우,
반드시 실제 API 키를 GitHub에 올리지 않아야 합니다.

- `.env` 또는 `.env.local` 같은 파일은 절대 커밋하지 않기
- 브라우저에 직접 키를 하드코딩하지 않기
- `.env.example` 파일을 통해 필요한 변수만 예시로 공유하기
- 로컬 환경에서만 키를 입력하고 테스트하기

예시:

```bash
cp .env.example .env
```

그리고 `.env` 파일에 본인 API 키를 입력해 주세요.

## 참고

- `.env.example` 파일을 복사해 로컬 환경에서 설정하세요.
- 실제 키는 개인 PC 또는 비공개 환경에서만 사용하세요.
