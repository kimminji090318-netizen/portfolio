# 딱맞뷰티

Google Apps Script 기반 퍼스널 컬러 진단 웹앱

## 프로젝트 소개
피부톤을 분석해 추천 색상, 메이크업 스타일, 패션 조합을 제안하는 웹 애플리케이션입니다.

## 프로젝트 목표
- 사용자의 피부톤 특성을 기반으로 퍼스널 컬러를 진단한다.
- 추천 색상과 메이크업 가이드를 제시한다.
- 패션 스타일과 화장품 추천을 제공한다.
- 진단 결과를 Google Sheets에 기록하여 관리한다.

## 핵심 기능
- 개인 정보 입력 화면
- 피부톤 분석 및 색상 판별
- 독자적으로 정의한 퍼스널 컬러 기준 적용
- 추천 화장품 및 메이크업 가이드
- 패션 코디 추천
- 진단 결과 자동 저장

## 기술 스택
- Google Apps Script
- HTML
- JavaScript
- CSS
- Google Sheets

## 실행 방법
1. Google Apps Script 프로젝트를 생성합니다.
2. `code.gs` 파일을 붙여넣습니다.
3. `index.html`을 HTML 서비스로 연결합니다.
4. 웹 앱을 배포하고 사용합니다.

## 주요 구현 포인트
- RGB 값을 Lab 색 공간으로 변환하는 알고리즘 적용
- 조명 환경 보정 로직 구현
- 응답형 UI 구성
- Google Script와 HTML 간 `google.script.run` 통신
- 자동 결과 저장 기능

## 배운 점
- 색상 이론을 실제 서비스에 적용하는 방법을 익혔습니다.
- HTML/CSS/JS 기반의 웹 UI를 제작하는 경험을 쌓았습니다.
- Google Apps Script를 활용한 서버리스 웹앱 개발을 이해했습니다.
- 사용자가 쉽게 이해할 수 있는 결과 화면을 설계하는 훈련을 했습니다.
