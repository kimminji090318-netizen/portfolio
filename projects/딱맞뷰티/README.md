# 딱맞뷰티

Google Apps Script 기반 퍼스널 컬러 진단 웹앱

## 프로젝트 소개
피부톤을 분석해 추천 색상, 메이크업 스타일, 패션 조합을 제안하는 웹 애플리케이션입니다. 이 프로젝트는 디지로그와의 기업 연계 프로그램을 통해 진행되었으며, 실제 피부 측정 데이터를 기반으로 퍼스널 컬러 진단 알고리즘을 개발한 고등학생의 첫 작품입니다.

## 프로젝트 정보
- **프로젝트 기간**: 2026.06.02 ~ 10.08 (5개월)
- **역할**: 팀장
- **팀 구성**: 팀장(본인) + 팀원 2명
- **협력 기업**: 디지로그(DIGILOG)

## 프로젝트 배경
디지로그의 피부 측정 기기에서 제공받은 데이터를 바탕으로 실제 사용자의 피부톤 특성을 분석할 수 있는 서비스를 만들고자 했습니다. 하지만 데이터는 총 92명으로 구성되어 있었고, 그중 여름쿨톤은 단 2명에 불과해 심각한 데이터 불균형이 발생했습니다. 이를 해결하기 위해 봄, 가을, 겨울의 평균값을 활용해 가상의 여름쿨톤 기준값을 설정하고, AI를 통해 여름쿨톤 가상 데이터를 생성했습니다. 이후 계층적 클러스터링을 적용하여 실제 데이터와 합성 데이터를 함께 분석함으로써 최종적인 여름쿨톤 기준값을 정립했습니다.

## 프로젝트 목표
- 실제 피부 측정 데이터를 기반으로 정확한 퍼스널 컬러를 진단한다.
- 사용자의 피부톤 특성을 분석해 추천 색상을 제안한다.
- 퍼스널 컬러에 맞는 메이크업과 패션 스타일을 가이드한다.
- 진단 결과를 Google Sheets에 기록하여 관리한다.

## 핵심 기능
- 개인 정보 입력 화면
- 피부톤 분석 및 색상 판별
- 데이터 기반 퍼스널 컬러 기준 적용
- 추천 화장품 및 메이크업 가이드
- 패션 코디 추천
- 진단 결과 자동 저장

## 기술 스택
- **프론트엔드**: HTML, CSS, JavaScript
- **백엔드**: Google Apps Script
- **데이터 관리**: Google Sheets
- **데이터 분석 & 머신러닝**: Python
- **머신러닝 기법**: AI 기반 합성 데이터 생성, 계층적 클러스터링
- **색상 처리**: RGB ↔ Lab 색 공간 변환, 조명 환경 보정 알고리즘

## 개발 여정

### 📊 데이터 분석 및 문제 인식
이 프로젝트의 가장 큰 도전은 데이터 불균형이었습니다. 92명의 피부 측정 데이터 중 여름쿨톤이 단 2명뿐이었기 때문에, 여름쿨톤을 기준으로 진단 로직을 만들면 결과가 편향될 가능성이 높았습니다. 이를 해결하기 위해 실제 데이터의 한계를 인정하고 보완 가능한 기준을 설계하는 과정이 필요했습니다.

### 🤖 AI 기반 데이터 보완
여름쿨톤의 데이터가 부족한 문제를 해결하기 위해 다음과 같은 프로세스를 구현했습니다:

1. **가상 기준값 설정**: 봄, 가을, 겨울 데이터의 RGB 평균값을 계산하여 가상의 여름쿨톤 기준값 정의
2. **AI 기반 합성 데이터 생성**: 설정된 기준값을 중심으로 정규분포를 따르는 여러 개의 여름쿨톤 데이터 생성 (Python 활용)
3. **통계적 보완**: 생성된 가상 데이터의 개수를 조정하여 각 톤별 데이터 비율을 최적화

이 과정을 통해 제한된 실제 데이터를 보완하면서도 통계적 신뢰도를 유지할 수 있었습니다.

### 📈 계층적 클러스터링을 통한 기준값 정립
생성한 가상 데이터와 실제 데이터를 통합하여 계층적 클러스터링(Hierarchical Clustering)을 적용했습니다:

1. **클러스터링 수행**: scipy의 linkage 함수를 사용하여 Ward 방식으로 계층적 클러스터링 실행
2. **클러스터 분석**: 각 퍼스널 컬러 그룹(봄, 여름, 가을, 겨울)이 정확히 4개 클러스터로 형성되는지 검증
3. **기준값 도출**: 각 클러스터의 중심값(centroid)을 계산하여 최종적인 퍼스널 컬러 기준값 확정

이 결과는 단순 평균값보다 실제 데이터의 분포를 더 잘 반영하며, 여름쿨톤을 포함한 모든 톤에 대해 통계적으로 타당한 기준을 제공했습니다.

### 🎨 색상 처리 알고리즘
사용자가 입력한 피부 색상 데이터를 정확하게 분석하기 위해 다음을 구현했습니다:

1. **RGB ↔ Lab 색 공간 변환**: RGB 값을 sRGB 표준화 후 XYZ를 거쳐 Lab 색 공간으로 변환 (CIE Lab 표준 적용)
2. **조명 환경 보정**: 실제 촬영 환경의 조명에 따른 색상 편차를 보정하는 로직 구현
3. **톤 판별**: 사용자 입력 피부톤과 기준값 간의 거리(유클리드 거리)를 계산하여 가장 적합한 퍼스널 컬러 판정

### 💻 웹앱 구현
데이터 분석을 바탕으로 실제 사용자에게 보여줄 수 있는 웹앱을 구현했습니다:

1. **프론트엔드 개발**: HTML/CSS/JavaScript를 사용하여 반응형 UI 구성 (모바일·데스크톱 대응)
2. **백엔드 연결**: Google Apps Script로 사용자 입력값을 처리하고 진단 로직 실행
3. **데이터 저장**: `google.script.run`을 활용한 비동기 통신으로 결과를 Google Sheets에 자동 저장
4. **결과 시각화**: 추천 색상 팔레트, 메이크업 가이드, 패션 조합을 직관적으로 표현

### 🎓 팀 역할 및 조정
- **팀장(본인)**: 프로젝트 전체 기획, 데이터 분석 전략 수립, 머신러닝 알고리즘 설계 및 구현, 웹앱 아키텍처 설계
- **팀원 1**: 데이터 전처리 및 통계 분석 지원
- **팀원 2**: 웹앱 UI/UX 디자인 및 프론트엔드 개발 보조

## 배운 점
- 실제 데이터가 부족한 상황에서 발생하는 불균형 문제를 인식하고 머신러닝으로 해결하는 방법을 배웠습니다.
- 색상 이론, 통계 분석, AI 기반 데이터 보완, 클러스터링 같은 고급 기술을 실제 서비스에 적용하는 경험을 했습니다.
- 제한된 환경과 불완전한 데이터 상황에서도 사용자에게 실질적으로 도움이 되는 웹앱을 만들 수 있다는 자신감을 얻었습니다.
- 기업 연계 프로젝트를 통해 실제 데이터를 다루는 책임감, 팀 리더십, 문제 해결 역량을 키웠습니다.

## 실행 방법
1. Google Apps Script 프로젝트를 생성합니다.
2. `code.gs` 파일을 붙여넣습니다.
3. `index.html`을 HTML 서비스로 연결합니다.
4. 웹 앱을 배포하고 사용합니다.
