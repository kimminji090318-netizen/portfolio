# 딱맞뷰티

Google Apps Script 기반 퍼스널 컬러 진단 웹앱

## 프로젝트 소개
피부톤을 분석해 추천 색상, 메이크업 스타일, 패션 조합을 제안하는 웹 애플리케이션입니다. 이 프로젝트는 **디지로그(DIGILOG)와의 기업 연계 프로그램**을 통해 진행되었으며, 실제 피부 측정 데이터의 불균형 문제를 AI와 머신러닝 기법으로 해결하여 만든 고등학생 첫 작품입니다.

## 프로젝트 배경
고등학생 시절 디지로그의 피부 측정 기기를 통해 수집된 데이터(비식별자 처리)를 활용하여 실제 사용자의 피부톤 특성을 분석할 수 있는 기회를 얻게 되었습니다. 이를 바탕으로 단순한 색상 추천을 넘어, 과학적 근거를 갖춘 퍼스널 컬러 진단 서비스를 만들고자 프로젝트를 시작했습니다.

## 프로젝트 목표
- 실제 피부 측정 데이터를 기반으로 정확한 퍼스널 컬러를 진단한다.
- 사용자의 피부톤 특성을 분석하여 추천 색상을 제시한다.
- 퍼스널 컬러에 맞는 메이크업과 패션 스타일을 가이드한다.
- 진단 결과을 Google Sheets에 기록하여 관리한다.

## 핵심 기능
- 개인 정보 입력 화면
- 피부톤 분석 및 색상 판별
- 데이터 기반 퍼스널 컬러 기준 적용
- 추천 화장품 및 메이크업 가이드
- 패션 코디 추천
- 진단 결과 자동 저장

## 개발 여정

### 📊 데이터 분석 및 문제 인식
이 프로젝트의 가장 큰 도전은 **심각한 데이터 불균형**이었습니다. 디지로그로부터 받은 92명의 피부 측정 데이터를 분석하던 중, 봄쿨톤, 가을쿨톤, 겨울쿨톤에 비해 여름쿨톤 데이터가 **단 2명**에 불과하다는 문제를 발견했습니다. 이러한 극심한 불균형으로는 신뢰할 수 있는 여름쿨톤 기준값을 설정할 수 없었습니다.

### 🤖 AI 기반 데이터 합성으로 해결
이 문제를 해결하기 위해 다음과 같은 전략을 세웠습니다:

1. **가상 기준값 설정**: 봄, 가을, 겨울의 실제 데이터 평균값으로부터 여름쿨톤의 가상 기준값을 지정
2. **AI를 활용한 합성 데이터 생성**: 설정된 기준값을 바탕으로 여름쿨톤의 특성을 가진 다양한 가상 데이터셋 생성
3. **계층적 클러스터링(Hierarchical Clustering)**: 생성된 가상 데이터와 실제 여름쿨톤 데이터(2명)를 함께 분석하여 최종적인 여름쿨톤 기준값 도출

이 접근 방식을 통해 제한된 데이터 환경에서도 머신러닝 기법으로 신뢰도 높은 진단 기준을 만들 수 있었습니다.

### 🎨 색상 이론 연구 및 알고리즘 개발
- RGB 색 공간의 한계를 인식하고 Lab 색 공간으로의 변환 학습
- 데이터 기반 조명 환경 보정 로직 구현
- 퍼스널 컬러 이론(Spring, Summer, Fall, Winter)을 실제 측정 데이터와 통계 기법으로 재정의
- 사용자 입력값과 실제/합성 측정 데이터 간의 매핑 로직 설계

### 💻 기술 선택 및 아키텍처
서버 비용 없이 빠르게 배포할 수 있는 방법을 찾아 **Google Apps Script**를 선택했습니다. 데이터 전처리와 머신러닝은 Python으로 수행하고, HTML/CSS/JavaScript로 사용자 인터페이스를 구성했으며, Google Sheets를 데이터베이스로 활용하는 구조로 설계했습니다.

### 🔨 개발 과정
1. **데이터 전처리**: 92명의 피부 측정 ��이터 정제 및 분석
2. **머신러닝 기반 데이터 합성**: AI를 활용한 여름쿨톤 가상 데이터 생성
3. **클러스터링 분석**: 계층적 클러스터링으로 최적의 퍼스널 컬러 기준값 결정
4. **색상 분석 알고리즘**: 실제/합성 측정 데이터를 기반으로 RGB → Lab 변환 로직 구현
5. **사용자 입력 인터페이스**: 피부톤 특성을 쉽게 입력할 수 있도록 UI 설계
6. **진단 로직**: 입력된 데이터와 확정된 퍼스널 컬러 기준값을 비교하여 진단
7. **결과 시각화**: 추천 색상 팔레트, 메이크업 가이드, 패션 조합을 시각적으로 표현
8. **자동 저장 기능**: Google Script와 HTML 간 `google.script.run`을 통한 비동기 통신으로 진단 결과 자동 기록
