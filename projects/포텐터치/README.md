# 포텐 터치 (Potential Touch)

> 직업계고 학생들을 위한 AI 기반 스마트 경험 기록 및 성찰 시스템

---

## 📋 프로젝트 소개

**포텐 터치**는 학교나 실습에서 경험한 활동을 기록하고, **Google Gemini AI**와의 대화를 통해 깊이 있게 성찰하는 웹앱입니다.

- ✍️ 활동 기록: 프로젝트, 동아리, 실습, 봉사활동 등을 카테고리별로 기록
- 🤖 AI 분석: 경험을 요약하고 핵심역량을 자동 추출
- 💬 AI 챗봇: 기록한 경험을 바탕으로 심층 질문 생성 및 성찰 대화
- 📊 패턴 분석: 전체 활동을 분석해 진로 방향 제안

---

## 🎯 주요 기능

### 1. 활동 기록 관리
- 활동명, 활동 유형, 기간, 상세 내용 입력
- 기록 수정/삭제 기능
- localStorage 기반 로컬 저장

### 2. AI 심층 분석 (3가지)
| 분석 유형 | 설명 | 활용 |
|---------|------|------|
| 요약 & 핵심역량 | 경험을 3줄로 요약하고 드러난 역량 3~5개 도출 | 생활기록부 작성 시 참고 |
| 심층 질문 생성 | 상황/역할/해결 과정을 성찰하는 5가지 질문 생성 | 자기소개서/면접 준비 |
| 활동 패턴 분석 | 전체 기록을 분석해 강점/약점/진로 방향 제안 | 진로 계획 수립 |

### 3. AI 챗봇 (선택 기록 기반)
- 특정 활동을 선택하고 AI 코치와 대화
- 기록 내용을 바탕으로 구체적인 질문 응답
- 전체 경험 기록 또는 개별 기록 기반 참고 가능

## 🔐 API 키 설정과 보안

- 실제 Gemini API 키를 HTML, JavaScript, README 또는 공개 저장소에 작성하지 않습니다.
- `.env.example`은 설정 예시일 뿐이며, 일반 브라우저용 HTML/JavaScript는 `.env` 파일을 자동으로 읽지 못합니다.
- 실제 API를 연결할 때는 백엔드 또는 서버리스 함수에서 `GEMINI_API_KEY` 환경변수를 읽고, 프런트엔드에서는 서버를 통해 요청하도록 구성해야 합니다.
- 공개 저장소에 실제 키를 올린 적이 있다면 코드에서 삭제하는 것만으로는 부족하므로 기존 키를 폐기하고 새 키를 발급하세요.

## 🧪 실행 상태 안내

이 저장소의 `index.html`은 현재 안내 문구만 들어 있는 자리표시 파일입니다. README에 적힌 기능은 프로젝트의 목표와 설계 설명이며, 실제 시연을 위해서는 완성된 웹앱 HTML 파일을 추가해야 합니다.
